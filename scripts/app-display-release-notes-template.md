# Sunshine App Display Profile {{RELEASE_TAG}}

本版基于 Foundation Sunshine 正式版 `{{UPSTREAM_RELEASE}}`，保留并增强「按应用指定显示目标、拓扑、分辨率、刷新率、HDR 与断开恢复策略」的定制能力，同时修复双显卡笔记本串流场景下的虚拟显示器断流问题。

## 项目能力

- **按应用显示方案**：配置应用显示方案时，由服务端覆盖客户端的显示目标和布局，并可按配置采用客户端分辨率、刷新率与 HDR 请求。
- **未配置入口严格跟随客户端**：未配置应用显示方案的 Desktop、Steam 和其他入口，继续遵循 Moonlight 客户端与全局显示请求，不写入任何额外显示字段。
- **方案切换**：保留同一 Moonlight 客户端通过「退出运行中的应用并运行此应用」切换不同应用显示方案的会话上下文。
- **虚拟显示器（VDD）**：复用基地版身份（`vdd_reuse` 决定 `shared_vdd` 或客户端标识）、创建、拓扑切换与恢复流程。
- **DualSense 组件**：Windows 安装包固定使用仓库锁定的控制面板，并校验上游正式版 DualSense 组件清单、下载地址、大小与摘要；控制面板下载组件时跟随系统代理。

## 客户端兼容

- **原版 Moonlight**（Android / iOS / Windows / Linux）：不发扩展参数时严格按基地版路径处理，串流当前活动显示器。
- **Moonlight V+**：解析其独有的 `useVdd` / `customScreenMode` / `resolutionScale` / `display_name` 参数：
  - 显式选择虚拟显示器布局（副屏 / 副主屏 / 独占）时，VDD 按所选布局激活；
  - 发送 `no_operation`（无操作）时全面跟随基地版语义——创建 VDD 但不强制拓扑，激活方式由 Windows 默认处理；
  - VDD 模式发布失败时不中止会话，按驱动实际发布的模式继续串流，退出时校正显示状态。
- **APP 显示方案优先级**：APP 配置 > 客户端显式请求 > 全局配置。

## 双显卡笔记本适配

混合显卡（dGPU + iGPU）笔记本在会话开始后约 1~6 秒会发生面板 GPU 路径切换，导致虚拟显示器输出从活动拓扑中掉出、采集丢失。本版包含：

- 会话启动约 3 秒主动重断言 VDD 拓扑，提前消除 GPU 路径切换造成的断流窗口；
- 拓扑重断言后按会话保存的分辨率 / 刷新率重新应用模式（避免回退到默认分辨率）；
- 主屏模式校验与修复（含历史设备身份回退），断流恢复后主屏分辨率与拓扑保持正确。

## 多屏电脑

已连接多台物理显示器的电脑不受影响：拓扑只在应用目标显示器时修改；「物理屏为主屏 + VDD 为副屏」保持；退出后恢复创建 VDD 前的物理拓扑并校验主屏模式。

## 显示行为

- `ensure_secondary`：物理显示器保持主屏，虚拟显示器作为副屏。
- `ensure_primary`：虚拟显示器作为主屏，物理显示器保持活动副屏。
- `ensure_only_display`：只保留目标虚拟显示器。
- Moonlight 仅断开串流连接时，按应用配置决定是否保持当前显示状态。
- 从 Moonlight 关闭运行中的应用时，按应用配置恢复创建虚拟显示器前的物理显示拓扑。

需要便携部署时，可使用 `{{PORTABLE_FILE}}`（解压后运行 `install_portable.bat` 或直接运行 `sunshine.exe`）。
